#  Tiny C Allocators collection

C Allocators collection to use in my own projects.

Feel free to use the code if you like but I really only meant it to be used by myself, therefore it is not namespaced.
It follows the [STB](https://github.com/nothings/stb) header-only style so if you do use it just include it in a *.c file and

```c
#define TCA_IMPLEMENTATION
```
